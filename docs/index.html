Summarizer.io

An extractive text-summarization web app built with Flask and spaCy.

The Text Summarizer takes a block of text and returns a shorter version by scoring sentences on normalized word frequency and keeping the highest-ranked ones.

Run locally

git clone https://github.com/ms-shashank/Summarizer.io.git
cd Summarizer.io
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS / Linux
pip install -r requirements.txt
python -m spacy download en_core_web_lg
python app.py

Endpoints

  • GET / — web form
  • POST / — form submit, renders the summary
  • POST /summarize — JSON {"text": "..."} returns {"summary": "..."}
